## Featured Projects

### [NeuroKonnect](https://neurokonect.site) — *under review*
End-to-end EEG connectomics framework. Sliding-window functional connectivity, HMM latent brain state modeling, LSTM cognitive state classification (>80% accuracy), and brain age regression (R²~0.59).

### [OpGene](https://github.com/sheraz) — *under review*
Optuna-based Python package for automated benchmarking of 12 ML classifiers with hyperparameter optimization on high-dimensional genomic datasets.

### GNN Multi-omics Patient Stratification
Graph neural network integrating transcriptomics + genomics for breast cancer subtype discovery and precision medicine patient stratification.

### Spatial Transcriptomics × MRI Integration — *under review*
Custom GNN pipeline combining spatial gene expression with MRI-derived imaging features to resolve spatially-patterned transcriptional programs.
